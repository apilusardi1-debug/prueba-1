03 — flujo completo de vida del cliente
01 Lead entra por WhatsApp o formulario
Origen: WhatsApp (webhook WuzAPI) o formulario público del sitio
Se crea: registro en leads con nombre, whatsapp, excursión de interés
Actividad: se registra lead_recibido en actividad_clientes una vez que exista el cliente
INSERT leads INSERT conversaciones Realtime → CRM
02 Conversación y seguimiento
El equipo responde por el CRM interno
El lead avanza por el Kanban: nuevo → contactado → reservado
Todo el historial de mensajes queda en mensajes
SELECT conversaciones INSERT mensajes UPDATE leads.estado
03 Lead se convierte en Cliente
Acción: el agente hace "Convertir lead" desde el CRM o Leads
Se crea registro en clientes con lead_id referenciando al origen
La conversación se vincula con cliente_id
INSERT clientes UPDATE leads.estado = 'reservado' UPDATE conversaciones.cliente_id INSERT actividad: lead_convertido
04 Se crea la Reserva
El agente crea la reserva: cliente + excursión + fecha + personas + precio
Estado inicial: pendiente hasta que el cliente confirme
Se vincula el vendedor que la tomó
INSERT reservas INSERT actividad: reserva_creada UPDATE clientes.cantidad_reservas +1
05 Se registran los Pagos
Puede haber varios pagos por reserva (seña + saldo)
Métodos: efectivo, transferencia, tarjeta, MercadoPago, crypto
Estado reserva cambia a confirmada cuando se recibe el pago total
INSERT pagos INSERT actividad: pago_registrado UPDATE reservas.estado = 'confirmada' UPDATE clientes.total_gastado
06 Operación del día — Agenda
El día de la excursión: el admin abre el calendario → click en el día → click en paseo → modal
Asigna chofer a cada pasajero, "Cerrar operación" envía WhatsApp al chofer
Al completarse: el estado de reserva pasa a completada
SELECT reservas por fecha UPDATE reservas.chofer_id UPDATE reservas.estado = 'completada' INSERT actividad: excursion_completada WhatsApp → Chofer
07 Historial completo del Cliente
En el perfil del cliente se puede ver todo ordenado por fecha:
Timeline: cuándo llegó como lead → cuándo reservó → cuántos pagó → qué excursiones hizo
Métricas: total gastado, cantidad de excursiones, última actividad
SELECT actividad_clientes WHERE cliente_id SELECT reservas WHERE cliente_id SELECT pagos WHERE cliente_id SELECT mensajes via conversaciones
04 — sql para crear las tablas
-- ─────────────────────────────────────────────────────────────
-- DREAMTOURS · HISTORIAL DE CLIENTES · Supabase SQL
-- ─────────────────────────────────────────────────────────────

-- 1. Campos nuevos en clientes
ALTER TABLE clientes
  ADD COLUMN IF NOT EXISTS email              text,
  ADD COLUMN IF NOT EXISTS pais               text,
  ADD COLUMN IF NOT EXISTS ciudad             text,
  ADD COLUMN IF NOT EXISTS lead_id            uuid references leads(id),
  ADD COLUMN IF NOT EXISTS total_gastado      numeric default 0,
  ADD COLUMN IF NOT EXISTS cantidad_reservas  int default 0;

-- 2. Link conversaciones con clientes
ALTER TABLE conversaciones
  ADD COLUMN IF NOT EXISTS cliente_id uuid references clientes(id);

-- 3. Reservas (relacionales, migrar desde mockData)
CREATE TABLE IF NOT EXISTS reservas (
  id               uuid primary key default gen_random_uuid(),
  cliente_id       uuid references clientes(id) on delete set null,
  excursion_id     uuid references excursiones(id) on delete set null,
  fecha            date not null,
  personas         int not null default 1,
  precio_unitario  numeric not null,
  total            numeric not null,
  moneda           text not null default 'USD',
  estado           text not null default 'pendiente',
  hospedaje        text,
  chofer_id        uuid references choferes(id),
  guia_id          uuid references guias(id),
  vendedor_id      uuid references vendedores(id),
  notas            text,
  created_at       timestamp with time zone default now(),
  updated_at       timestamp with time zone default now()
);

-- 4. Pagos
CREATE TABLE IF NOT EXISTS pagos (
  id               uuid primary key default gen_random_uuid(),
  reserva_id       uuid references reservas(id) on delete cascade,
  cliente_id       uuid references clientes(id) on delete set null,
  monto            numeric not null,
  moneda           text not null default 'USD',
  metodo           text not null,
  estado           text not null default 'pendiente',
  fecha_pago       date,
  comprobante_url  text,
  notas            text,
  created_at       timestamp with time zone default now()
);

-- 5. Timeline de actividad por cliente
CREATE TABLE IF NOT EXISTS actividad_clientes (
  id          uuid primary key default gen_random_uuid(),
  cliente_id  uuid references clientes(id) on delete cascade,
  tipo        text not null,
  titulo      text not null,
  descripcion text,
  metadata    jsonb default '{}',
  created_at  timestamp with time zone default now()
);

-- 6. Notas internas por cliente
CREATE TABLE IF NOT EXISTS notas_clientes (
  id          uuid primary key default gen_random_uuid(),
  cliente_id  uuid references clientes(id) on delete cascade,
  contenido   text not null,
  autor       text,
  created_at  timestamp with time zone default now()
);

-- Índices para búsquedas frecuentes
CREATE INDEX IF NOT EXISTS idx_reservas_cliente    ON reservas (cliente_id);
CREATE INDEX IF NOT EXISTS idx_reservas_fecha      ON reservas (fecha);
CREATE INDEX IF NOT EXISTS idx_pagos_reserva       ON pagos (reserva_id);
CREATE INDEX IF NOT EXISTS idx_pagos_cliente       ON pagos (cliente_id);
CREATE INDEX IF NOT EXISTS idx_actividad_cliente   ON actividad_clientes (cliente_id, created_at desc);
